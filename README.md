# UIU V2.0 Student Attendance System - Final Year Project
A web-based attendance management system built for a university setting, supporting three user roles: Admin, Lecturer, and Student. The system digitizes manual attendance marking while adding real-time attendance percentage tracking and automatic warnings for students who fall below the required attendance threshold.

## Features
**[Admin]** <br>
• Manage Lecturer, Student, Course, and Faculty records (Add, Edit, Remove) <br>
• Assign Lecturers to Courses and Faculties <br>
• Enroll Students into multiple Courses <br>
• Create and remove class sessions <br>
• View and correct attendance records <br>
• View attendance percentage reports per course <br>
• Search and sort across management pages<br>
<br>**[Lecturer]** <br>
• View only their own assigned courses<br>
• Mark student attendance per session (Attended / Absent / Absent with Excuse)<br>
• View attendance history and percentage per course<br>
• Search and sort student lists<br>
<br>**[Student]** <br>
• View enrolled courses and personal attendance history <br>
• View real-time attendance percentage per course <br>
• Receive an automatic "Barred" warning if attendance falls below 70% <br>
